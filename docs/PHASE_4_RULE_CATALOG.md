# Phase 4 — Deterministic Rule Catalog

## 1. Controlled Rule Types
- `BOOLEAN_FACT`
- `NUMERIC_THRESHOLD`
- `PERCENTAGE_THRESHOLD`
- `ENUM_MATCH`
- `IDENTITY_MATCH`
- `COMPOSITE_ALL`
- `COMPOSITE_ANY`

## 2. Seeded Compliance Rules
1. `RULE_GST_ACTIVE`: Checks `GST_GST_STATUS == 'ACTIVE'`.
2. `RULE_DEBARMENT_CHECK`: Checks `DEBARMENT_DEBARMENT_STATUS == 'NOT_DEBARRED'`.
3. `RULE_UDYAM_MSME`: Checks `UDYAM_MSME_STATUS == 'ACTIVE'`.
4. `RULE_TURNOVER_THRESHOLD`: Checks `ANNUAL_TURNOVER_FY24 >= 500,000,000` (Rs 50 Cr).
5. `RULE_MAKE_IN_INDIA`: Checks `LOCAL_CONTENT_PERCENTAGE >= 50.0%` (Class-I Supplier).
6. `RULE_OEM_AUTHORIZATION`: Checks `OEM_AUTH_AUTHORIZATION_STATUS == 'VALID'`.
